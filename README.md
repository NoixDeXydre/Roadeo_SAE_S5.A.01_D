## **Contribuer**

### Git

Pour les contributions conséquentes, il sera préférable de faire un pull-request.  
Cela permet de faire des revues de code et de voir l'avancé de chacun sur une implémentation particulière.

Si la contribution est petite et n'a pas besoin de vérifications, il est possible de l'implémenter directement dans le dépôt.

Pour être à jour dans une branche, privilégier `git pull --rebase`
